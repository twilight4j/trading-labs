## 상승여력 계산

2년 후 연간 당기순이익(지배) 을 현재 시가총액에  대입하면 적정 시가총액을 구할 수 있음
현재 시가총액과 적정 시가총액을 비교하여 상승 여력 분석

- 2년 후 연간 당기순이익(지배) 예상치(E)
- 현재 시가총액 (P)
- PER 는 기본값 10

> 적정 시가총액(K) = E x PER(10)

> 상승여력(D) :  (적정 시가총액(K) / 현재 시가총액(P) - 1 ) x 100


**삼성전자 예시**
- 28년 당기순이익(지배) 예상치 (E) : 4,744,728 억 (474.4조)
- 현재 시가총액 (P) : 16,749,588억 (1,674.9조)

> 적정 시가총액(K) = E x PER

PER 를 10으로 잡았을 때,

적정 시가총액(K) : 474.4(E) x 10(PER) = 4,744 조

> 상승여력(D) : (적정 시가총액(K) / 현재 시가총액(P) - 1 ) x 100 = 183.27%
